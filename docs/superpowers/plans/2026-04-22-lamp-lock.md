# 灯绳锁屏组件 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在 pandaSleepAdmin2.0 顶部添加灯绳 SVG 入口，拉动后以滑入+回弹动画弹出全屏夜空遮罩，遮罩中央显示带闭眼的台灯插画（定向光束），点击遮罩任意处收起。

**Architecture:** 单文件组件 `src/components/lampLock/index.vue`，内含灯绳固定入口与 Teleport 全屏遮罩。状态由单个 `ref<boolean> isLocked` 驱动，所有动画纯 CSS @keyframes，无外部依赖。在 `src/layout/index.vue` 引入即可全局生效。

**Tech Stack:** Vue 3 Composition API、TypeScript、CSS @keyframes、SVG、`<Teleport>`

### Task 1：创建组件骨架与灯绳 SVG

**Files:**
- Create: `src/components/lampLock/index.vue`

- [ ] **Step 1：创建组件文件，写入 script 骨架**

```vue
<script setup lang="ts">
import { ref } from 'vue'

const isLocked = ref(false)
const isPulling = ref(false)

const pullCord = () => {
  if (isPulling.value) return
  isPulling.value = true
  setTimeout(() => {
    isPulling.value = false
    isLocked.value = true
  }, 250)
}

const unlock = () => {
  isLocked.value = false
}
</script>
```

- [ ] **Step 2：为遮罩添加关闭（滑出）动画**

在 `src/components/lampLock/index.vue` 的 script 中，将状态扩展为：

```ts
import { ref } from 'vue'

const isLocked = ref(false)
const isClosing = ref(false)
const isPulling = ref(false)

const pullCord = () => {
  if (isPulling.value || isLocked.value) return
  isPulling.value = true
  setTimeout(() => {
    isPulling.value = false
    isLocked.value = true
    isClosing.value = false
  }, 250)
}

const unlock = () => {
  if (isClosing.value) return
  isClosing.value = true
  setTimeout(() => {
    isLocked.value = false
    isClosing.value = false
  }, 450)
}
```

在遮罩 div 上追加 class 绑定：

```vue
<div
  v-if="isLocked"
  class="lock-overlay"
  :class="{ closing: isClosing }"
  @click="unlock"
>
```

在 `<style scoped>` 中追加关闭动画：

```css
.lock-overlay.closing {
  animation: slideUp 0.45s ease-in forwards;
}

}
```
